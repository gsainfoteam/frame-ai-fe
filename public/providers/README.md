# Provider logos

These assets identify model suppliers. They are served locally; loading the model picker does not send image requests to a third-party logo service.

The SVG assets come from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/ea434b96e75813517b377825e01c0df61dee8836/packages/static-svg/icons), commit `ea434b96e75813517b377825e01c0df61dee8836` (MIT). See `LICENSE-LobeHub.txt` for the copyright and license notice. Brand names and marks belong to their respective owners.

`heygen.png` is the HeyGen site favicon, retrieved from the favicon URL used by [OpenRouter's video model collection](https://openrouter.ai/collections/video-models) on 2026-11-10: `https://t0.gstatic.com/faviconV2?client=SOCIAL&type=FAVICON&fallback_opts=TYPE,SIZE,URL&url=https://heygen.com&size=256`. This brand asset is not covered by the LobeHub license.

Unknown suppliers use a letter fallback. Add new, verified assets and source information here when extending `ProviderLogo.tsx`.
